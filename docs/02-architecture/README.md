# Architecture Documentation

This directory contains the system architecture, boundaries, contracts, decisions, and technical design records for the Autonomous AI Agency.

## Planned Documents

- `SYSTEM-ARCHITECTURE.md` — logical and physical architecture.
- `MODULE-BOUNDARIES.md` — responsibilities and dependency rules.
- `WORKFLOW-ARCHITECTURE.md` — durable workflow and state-transition design.
- `API-ARCHITECTURE.md` — API conventions and service boundaries.
- `EVENT-CONTRACTS.md` — internal events and asynchronous contracts.
- `SECURITY-ARCHITECTURE.md` — security boundaries and trust zones.
- `DATA-FLOW.md` — customer data and artifact movement.
- `ADR/` — Architecture Decision Records.

## Rule

An architectural decision that materially affects implementation, security, cost, or operations should be documented before it becomes difficult to change.
